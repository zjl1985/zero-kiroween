ACTIVE ENVIRONMENT: Generated village art, 2026-11-22 Asia/Shanghai

The current environment uses four real cursor.studio.GenerateImage calls made
for the user's explicit request to redraw higher-detail pixel scenery. The tool
exposes no model selector; no particular model or "best model" is claimed.
The supplied full-scene target was style reference only, never used as a backdrop.
No generated characters were copied. Gameplay/character/weapon art is unchanged.

Original generation outputs: generated/raw/{cottages,nature-props,surfaces,yard-details}.jpg
Extracted transparent sprites / periodic surface tiles: generated/*.png
Exact hashes, extraction boxes and processing: generated/PROVENANCE.json
Rebuild: python3 scripts/prepare-generated-village.py (Pillow + numpy)
Runtime: src/render/village-pixels.ts (synchronous indexed rows, offline/worker safe)

Processing: JPEG chroma key and alpha cleanup; connected sprite silhouettes;
nearest-neighbour common logical lattice; 224-colour shared palette quantization;
small opposite-edge crossfade for seamless repeating ground. House anchors are
at their doorsteps; other objects retain independent bottom footpoints/Y sorting.

The older pack below is retained on disk solely to preserve previous local work.
It is NOT read by the active generated compiler and supplies NO active pixels.
Its CC0 status does not apply to the newly generated art.
