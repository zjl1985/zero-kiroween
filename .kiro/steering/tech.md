# Tech stack

- TypeScript 5 (`strict`, ES2022, Node16 modules), compiled by `tsc` from `src/` to `dist/`. `scripts/build-site.mjs` packages only HTML, CSS and current compiled JS into `site/`; source maps and stale outputs stay out. Node.js 22+. No framework, no bundler, no runtime dependencies.
- Architecture: definitions + hooks + registries. `src/engine/` holds content-agnostic tools (`createRegistry`, `createEventBus`, `cachedSprite`). `src/defs/` holds one def file per cat, weapon, passive, evolution, enemy, material, reaction row, prop, landmark and biome, registered with one line in `src/defs/index.ts` or `src/defs/world-index.ts`. `src/game/` is the generic simulation that looks defs up by id and calls their hooks through a `SimContext`. Art files sit beside their defs and are registered only by `src/render/art-index.ts`, so the sim never imports art.
- Rendering: Canvas 2D. `src/main.ts` draws into a 2x internal back canvas, then presents it to the stage canvas. The 960 x 540 view follows the cat through a bounded world via `src/render/camera.ts`; ground (roads, landmark ground, district patches) is cached per chunk on 2x offscreen canvases (`craft-world.ts`), tall pieces and props are cached sprites (`cachedSprite`), and actors are culled to the view. New art uses the paper kit (`paper-kit.ts`, `prop-kit.ts`) and seeded variants (`variants.ts`).
- Paper interactions: 6 materials, 27 unique material x element rows (four `wash-*` rows for the appended `water` element), 18 props (the last is `water-bucket`, which spills through `PropDef.onScraps`). `src/game/props.ts` handles hits, capped fire and safe lifecycle; `paper-status.ts` handles player/enemy burn/wetness. Shots use `elements[0]`; Nicole and crane launches explicitly emit fold, smudge landings and vats emit ink. Ink suppresses fuel for 9 s; fold disables colliders for 5 s and waits for safe unfolding. Five flora defs regrow with delayed occupancy/fire checks and lifetime no-farm loot. Landmark pop-up folding remains a separate render-only effect (`POPUP`).
- Wash-out: `src/defs/wash.ts` (`WASH`) owns the numbers; `src/game/wash.ts` runs a sparse 32-unit colour grid in `SimState.wash` (max 600 cells, 0.25 s tick, rolls by `hash2`, never the step RNG). Cells are painted (not stored), colourless (level >= 0.5, pencil showing) or blank (Eraser). `SimContext.wash` / `SimContext.paint` are the hooks; `EnemyDef.pigment` and `wakesOn: 'colourless'` drive restoration and sketch spawns; `CharacterDef.dashTrail` marks cut holes only on colourless cells, and fold protection is kept as `SimState.wash.folds` circles, so painted ground stores no cells. Rendering: `render/wash-art.ts` (`washFrame` returns null after one empty check, so an unwashed run does no mask work; per-chunk blot masks rebuilt only on signature change; tide lines, wet film, blank, cut-hole blots, blooms), `pencil.ts` primitives, `sprite-sketch.ts` (cached `sketch:<id>:<q>` variants and pooled scratch canvases for live actors) and pencil chunk tiles (`buildChunk(..., 'sketch')`) sharing the same 14-tile budget.
- Paper verbs: `weapons/paper-cut.ts` (Zero pool) and `weapons/page-fold.ts` (Nicole pool) with pure geometry in `src/defs/weapons/paper-geometry.ts`; `SimState.cut`, `SimState.fold`, temporary `SimState.walls` that `safePosition` treats like scenery. `ctx.elementHit` accepts an optional `within` polygon.
- Paper ruleset and value: `src/render/paper-rules.ts` (`PAPER_LIGHT` top-right, `PAPER_SHADOW` down-right, 1 to 3 layers, `PAPER_VALUE`) with flat helpers in `paper-kit.ts`; `paper-value.ts` grades baked ground/decor tiles and adds the lit rim to cached enemy parts and the live cat; `withFlatShadows` makes cached scenery cast hard down-right shadows. No render module sets `ctx.filter` per frame (only the gallery value check, once).
- Water: `src/defs/water.ts` owns pure polygon helpers/tuning; landmark/biome defs provide shapes; world-gen adds explicit road crossings and caches local regions. `game/water.ts` uses radius-swept collision / spawn projection; `render/water-art.ts` draws identical vertices. Shallow speed is x0.68, deep blocks, decks are dry; (1040, 420) is the fully shallow teaching basin.
- Fire: 24-unit cells, max 40, 0.2 s tick, hash spread, no exposed-water cells. Radius contact gives 3 s carried burn, cat 1 HP/1 s through normal defenses, enemy 0.4/0.2 s. Water extinguishes before burn damage and grants 1.25 s wet protection, including when the fire grid is empty. Card/cloth are flammable (0.45/0.65). The old fire-safe-cat rule is superseded.
- Landmark actions: `defs/landmark-activities.ts` owns shared court anchors, rewards and tuning; `game/landmark-actions.ts` keeps per-placement progress/cooldown/wind/turn in `SimState.landmarkEvents`. Teahouse/observatory charge by proximity, greenhouse/windmill by fold/wind hits. `DecorPiece.live` renders the windmill rotor with a finite texture cache and sim-owned angle; no time/angle keys. Detailed contracts: `.kiro/skills/midnight-meow-dev/references/paper-ecology.md`.
- UI: plain DOM in `index.html` plus `styles.css`; screens are `title`, `play`, `pause`, `upgrade`, `result`, plus the `?gallery=1` page. HUD and result page canvases are painted by `src/render/journal-ui.ts` and repaint only when their inputs change.
- Simulation is deterministic: seeded RNG (`src/game/rng.ts`) passed only to `WeaponDef.step` and `EnemyBehaviour.steer`, state stored in `SimState`, advanced by `step(state, input, dt)`. Registration order is part of the behaviour. Rendering must not consume RNG or mutate simulation state. World content (chunks, districts, landmarks, roads, decor, props) comes from a pure hash of (seed, chunk coords) in `src/game/world-gen.ts` that both sim and renderer may call. Fire spread and prop drops use `hash2`, never the step RNG. Presentation slow motion (`src/render/timeline.ts`) only changes how many `FIXED_DT` steps run per frame.
- Audio: Web Audio only (`src/audio/sfx.ts`), oscillators and generated noise, no audio files. The `AudioContext` starts on the first pointerdown / keydown; `main.ts` derives cues from sim counters, so the sim stays audio-free.
- Art/status: `paper-face.ts` derives cached visible color contours from untouched official rectangle data for world heads and portraits. Enemy/combat cuts use finite cached parts; `paper-status-art.ts` adds read-only flame/char, wet, steam, ink-wash, regrow and reward cues. `ui/environment-copy.ts` prioritizes localized hazard guidance and real court actions.
- Preferences (locale, chosen cat, `muted`) are stored in `localStorage` under `midnight-meow-prefs`.

## Commands

```bash
npm ci          # TypeScript only
npm run build   # tsc -> dist/; static publish output -> site/
npm start       # python3 -m http.server 4173 --directory site
npm test        # npm run build && node --test tests/*.test.mjs
```

- Open `http://localhost:4173/`; `/?start=1` jumps straight into a run with the saved cat, `?seed=N` pins the run seed (otherwise each run gets a fresh one), `/?gallery=1` shows every registered entry on paper cards.
- An old local server may still hold port 4173. Check the port before starting another one.
- Tests import compiled modules from `dist/` and inspect the static output in `site/`, so they always run the production build first.
- `vercel.json` uses `npm ci`, `npm run build`, output `site/`, no framework or SPA fallback. The production site needs no Python, server process or environment variables. The user confirmed the previous Vercel deployment works; the latest local visual refinement still requires publication and visual review.

## Conventions

- ES module imports use the `.js` suffix (`./sim.js`) as required by Node16 resolution.
- Every user-facing string goes through `t(locale, key)` in `src/content/i18n.ts`. Add new keys to `src/content/keys.ts` and to every language pack.
- Gameplay numbers live in def files, not inline in render or UI code: per cat in `src/defs/cats/<id>/stats.ts`, per weapon / passive / enemy / prop / landmark in its def file, build and XP in `src/defs/progression.ts`, horde pacing, elites, spawn table and waves in `src/defs/horde.ts`, fire in `src/defs/fire.ts`, water in `src/defs/water.ts`, wash-out in `src/defs/wash.ts`, lifecycle in `src/defs/ecology.ts`, treatments in `src/defs/reactions/paper-status.ts`, activities in `src/defs/landmark-activities.ts`, districts in `src/defs/biomes/districts.ts`, interactions in `src/game/interactions.ts`, world size in `src/game/world-gen.ts`, shared `STATS` / `EFFECT_LIFE` / `FX_CAP` in `src/game/types.ts`. The facades `src/game/characters.ts`, `upgrades.ts` and `enemies.ts` re-export registry data under the old names. Presentation timing (cue beats, slow motion, card deal, pop-up fold) lives in `src/render/timeline.ts`.
- `src/game/*.ts`, non-legacy `src/render/*.ts`, `src/ui/*.ts` and `src/main.ts` must not name cat ids; look them up through the registries (tested).
- Verification is `npm run build` and `npm test`, plus at most one static screenshot. No animation or recording runs. Latest verification passed build and **295 tests** (new suites in the wash-out round: paper-rules, wash, paper-verbs, paper-value, plus extended paper-visuals and gallery). The one allowed screenshot of that round failed (Chrome headless exit 134 in the sandbox, no image); no animation/recording/audio/FPS checks, full gameplay/mobile review or user approval.
- Delete files with `trash` (moves to the macOS Trash). Never silently fall back to permanent deletion for untracked user files.
- Commit messages use gitmoji plus a type prefix, for example `✨ feat: ...`, `📝 docs: ...`.
